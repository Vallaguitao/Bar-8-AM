## 🚀 Deployment

This site is designed for GitHub Pages. See `GITHUB_SETUP_TUTORIAL.html` for step-by-step instructions.

### Quick Deploy

1. Create a new GitHub repository
2. Upload all files (keep folder structure)
3. Go to Settings → Pages
4. Set Source: Deploy from branch → main → / (root)
5. Wait 1-3 minutes for deployment
