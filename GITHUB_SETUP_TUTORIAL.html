🌐 Method 1: GitHub Web Interface (Easiest)

No software installation required — do everything in your browser!

Step 1 Create a New Repository

  1. Go to github.com and sign in
  2. Click the + icon in the top-right corner
  3. Select "New repository"
📸 Screenshot: Click the + button → New repository

Step 2 Configure Repository Settings

Fill in the following:

Field Value
Repository name bar-8-am (or any name you prefer)
Description Bar 8 AM - Premium bar website (optional)
Visibility Public (required for free GitHub Pages)
Initialize with README Leave unchecked

Click "Create repository"

Step 3 Upload Your Files

  1. On your new repository page, click "uploading an existing file" link
  2. Open your file explorer and navigate to your extracted bar8am folder
  3. Select ALL files and the images folder, then drag them into the upload area
  4. Wait for all files to upload (you'll see a progress bar)
⚠️ Important!

Make sure you drag the contents of the bar8am folder, not the folder itself. Your repository root should contain index.html directly, not a subfolder.

Step 4 Commit Your Files

  1. Scroll down to "Commit changes"
  2. Enter a commit message: Initial upload - Bar 8 AM website
  3. Click "Commit changes"
✅ Files Uploaded!

Your files are now on GitHub. Next, let's enable GitHub Pages.

💻 Method 2: Using Git Command Line

For those comfortable with terminal/command prompt.

Step 1 Install Git (if not installed)

Download from: git-scm.com/downloads

Step 2 Create Repository on GitHub

Follow Steps 1-2 from Method 1 to create an empty repository.

Step 3 Open Terminal/Command Prompt

Navigate to your extracted bar8am folder:

# Windows (Command Prompt)
cd C:\Users\YourName\Downloads\bar8am

# Mac/Linux
cd ~/Downloads/bar8am

Step 4 Initialize and Push

# Initialize git repository
git init

# Add all files
git add .

# Commit files
git commit -m "Initial upload - Bar 8 AM website"

# Set main branch
git branch -M main

# Connect to your GitHub repository (replace YOUR_USERNAME with your GitHub username)
git remote add origin https://github.com/YOUR_USERNAME/bar-8-am.git

# Push to GitHub
git push -u origin main
💡 First Time Using Git?

You may need to configure your identity first:

git config --global user.name "Your Name"
git config --global user.email "your.email@example.com"

⚙️ Enable GitHub Pages

This is the crucial step that makes your site live!

Step 1 Go to Repository Settings

  1. Navigate to your repository on GitHub
  2. Click the "Settings" tab (gear icon)

Step 2 Find Pages Settings

  1. In the left sidebar, scroll down and click "Pages"

Step 3 Configure Source

Setting Value
Source Deploy from a branch
Branch main
Folder / (root)

Click "Save"

📸 Screenshot: Settings → Pages → Source: Deploy from branch → main → / (root) → Save

Step 4 Wait for Deployment

  • GitHub will start building your site
  • This usually takes 1-3 minutes
  • Refresh the Settings → Pages section to see the status
🎉 Your Site is Live!

🔧 Troubleshooting

❌ 404 Error - Page Not Found

  • Make sure index.html is in the root of your repository, not in a subfolder
  • Check that GitHub Pages source is set to main branch and / (root)
  • Wait a few minutes — deployment can take time

❌ Images Not Loading

  • Verify the images folder was uploaded
  • Check that image filenames match exactly (case-sensitive!)
  • Ensure no special characters in filenames (we fixed this: Piña → Pina, Rosé → Rose)

❌ CSS Not Applied / Broken Layout

  • Verify styles.css is in the root folder
  • Hard refresh: Ctrl+Shift+R (Windows) or Cmd+Shift+R (Mac)
  • Clear browser cache

❌ Changes Not Showing

  • GitHub Pages can take 1-10 minutes to update
  • Check the "Actions" tab in your repository for deployment status
  • Hard refresh your browser

🔄 Making Updates

Using GitHub Web Interface:

  1. Go to your repository
  2. Navigate to the file you want to edit
  3. Click the pencil icon (Edit)
  4. Make your changes
  5. Click "Commit changes"
  6. Wait 1-3 minutes for the site to update

Using Git Command Line:

git add .
git commit -m "Update: description of changes"
git push
